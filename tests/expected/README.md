# Golden runs

Reference outputs used to self-test the validator and the evaluation harness.

| Scenario | Case | What it demonstrates |
|---|---|---|
| business-rules | `good-run/RUN-20261025T044345Z` | A full six-phase cycle. Boundary tests (in `good-run/workspace-changes/`) find the seeded defect at 500.00. 9 PASS, 1 FAIL, DEF-001, `NOT_READY`, closure `COMPLETE`. |
| missing-environment | `good-run/RUN-20261025T044700Z` | Honest reporting when tests cannot run: 2 BLOCKED (`environment_failure`), 2 NOT_RUN, no PASS, `NOT_READY`, closure `INCOMPLETE`. |

The test execution and evidence logs are real. The commands were run on 2026-10-25 against prepared fixture workdirs (Python 3.12.1, macOS). Absolute paths in tracebacks are redacted to `<workdir>` / `<python-home>`. The Markdown artifacts were written to the skill contract while the skill was being implemented. They are reference outputs, not the output of a specific agent.

Negative controls (fabricated PASS, count mismatch, leaked secret, unsupported READY, …) are generated by mutating these runs in `tests/evaluations/test_validate_artifacts.py`, so no deliberately bad artifacts are stored.
